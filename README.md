# Лабораторная работа 3 — компьютерная графика

Приложение на Qt 6. Для сборки нужны CMake 3.16+, компилятор C++20 и Qt 6 с модулями Core, Gui и Widgets:

```sh
cmake -S . -B build
cmake --build build
```

## Управление

1. В режиме «Рисовать границу» обведите мышью замкнутую область. Внутри можно нарисовать замкнутые контуры отверстий.
2. Для заливки цветом выберите «Заливка сериями» и щёлкните внутри области.
3. Для заливки рисунком нажмите «Загрузить изображение», выберите графический файл и щёлкните внутри области в режиме «Заливка изображением». Рисунок используется в исходном размере. Он привязан к координатам холста: если размер файла меньше холста по одной из осей, рисунок циклически повторяется по этой оси; если файл больше холста, используется соответствующий фрагмент без масштабирования.
4. Для отрезка выберите «Отрезок Брезенхема» или «Отрезок Ву» и протяните мышь от начальной до конечной точки. Цвет задаётся кнопкой «Цвет границы».
5. Кнопка «Очистить» возвращает белый холст.

Окно можно уменьшать: если холст не помещается целиком, используйте полосы прокрутки.

Заливка рисунком реализована рекурсивным обходом горизонтальных серий пикселей. Отдельная маска посещённых пикселей позволяет корректно обрабатывать рисунки, содержащие исходный цвет области и прозрачные точки. Алгоритм Ву смешивает цвет отрезка с фоном пропорционально покрытию двух соседних пикселей.
